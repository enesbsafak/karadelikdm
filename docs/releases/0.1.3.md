# Karadelik Download Manager 0.1.3

- **Torrent paylaşma artık isteğe bağlı:** Torrent bitince varsayılan olarak paylaşılmaz ve dosyalar hemen serbest
  kalır. Önceden bitince kendiliğinden paylaşılıyordu; paylaşılırken dosyalar açık tutulduğu için torrentle indirilen
  kurulum programı "dosya kullanılıyor" diyerek çalışmıyordu.
- **Paylaş / Paylaşmayı durdur:** Bitmiş torrentin satırında ve sağ tık menüsünde. Yeniden paylaşmadan önce dosyalar
  doğrulanır; eksik, değişmiş ya da bozuksa hiçbir şey indirilmez.
- Tercihler > BitTorrent: "Torrent bitince paylaşmaya devam et" kutusu. Paylaşma oranı 0 ise siz durdurana kadar
  paylaşılır.

Kurulum programı henüz kod imzalı değil: Windows SmartScreen ilk çalıştırmada "Ek bilgi > Yine de çalıştır" ister.
Önceki sürümler uygulama içinden güncellenebilir.
