# Karadelik Download Manager 0.1.0

İlk sürüm.

- Çok bağlantılı, kaldığı yerden devam eden HTTP(S), FTP ve FTPS indirmeleri; tek dosyaya doğrudan yazma, birleştirme aşaması yok
- BitTorrent ve magnet: DHT, dosya seçimi, kaldığı yerden devam, web seed (BEP 19), paylaşma oranı
- HLS ve MPEG-DASH akışları: kalite ve ses seçimi, AES-128, ffmpeg ile tek MP4
- Kuyruklar, zamanlayıcı, indirme kotası, kuyruk bitince uyku / kapatma
- Chrome, Edge ve Firefox uzantısı: indirme yakalama, sağ tık menüsü (magnet dahil), medya tespiti
- Site Grabber ve ZIP önizleme (yalnız seçilen dosyaları indirme)
- Kategoriler, pano izleme, antivirüs taraması, Türkçe ve İngilizce arayüz
- Apple tarzı arayüz, Karadelik DM'e özel ikon
- Telemetri yok

Kurulum programı henüz kod imzalı değil: Windows SmartScreen ilk çalıştırmada "Ek bilgi > Yine de çalıştır" ister.
